# Vogelwijs

Leer Nederlandse vogels herkennen aan uiterlijk en geluid, van merel tot dwaalgast. Geen account nodig: je voortgang blijft in je eigen browser.

Foto's en geluiden komen van [iNaturalist](https://www.inaturalist.org), gedeeld onder Creative Commons-licenties. Bij elke foto en opname staat de maker.
